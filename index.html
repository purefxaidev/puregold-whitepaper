    วิธีติดตั้งบน Android

    1. กดดาวน์โหลด APK 0.9.5 แล้วอนุญาตติดตั้งจากแหล่งที่ไม่รู้จักหากระบบถาม

    3. ในเมนู → ตั้งค่า วาง API key เพื่อเปิด PureFxAi

    วิธีติดตั้งบน iPhone / iPad

    1. เปิดหน้านี้ใน Safari (ไม่ใช้ Chrome หรือแอปแชท)
    2. แตะปุ่มแชร์ แล้วเลือก «เพิ่มไปยังหน้าจอโฮม»
    3. แตะ «เพิ่ม» จะได้ไอคอน PureGold เปิดเต็มจอเหมือนแอป

    การแจ้งเตือนเว็บแอปบน iOS ยังไม่เปิดในเวอร์ชันนี้

    Install on Android

    1. Download APK 0.9.5 and allow unknown sources if Android asks.
    2. You can install over the previous version.
    3. In More → Settings, paste an API key to enable PureFxAi.

    Install on iPhone / iPad

    1. Open this page in Safari (not Chrome or an in-app browser).
    2. Tap the Share button, then Add to Home Screen.
    3. Tap Add. PureGold opens full screen like an app.

    Web-app notifications on iOS are not enabled in this version.
