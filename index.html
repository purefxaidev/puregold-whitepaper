Vision

PUREGOLD is a mobile app for people who follow Thai gold (Hua Seng Heng) and world gold XAUUSD in one place. Built by PureFxAi to surface prices, educational trade plans, charts, techniques, and the latest news — with Nong Mee as the brand mascot.

  • เมนูแผน สัญญาณเข้า–ออกเพื่อการศึกษา และประวัติความแม่นยำ
  • ข่าวล่าสุดหลายแหล่ง พร้อมลิงก์ต้นทาง
  • PureFxAi วิเคราะห์ข่าวว่าหนุนหรือกดดันทอง และแจ้งเตือนข่าวแรงได้
  • แชท PureFxAi · วิดเจ็ตหน้าจอหลัก · หน้าต่างลอยทับแอปอื่น

Product highlights

  • Home shows chart and techniques plus Thai / XAU prices and short-term bias
  • Plan tab with educational entry/exit levels and signal accuracy history
  • Latest multi-source gold news with original links
  • PureFxAi analyzes whether headlines support or pressure gold, with optional strong-news alerts
  • PureFxAi chat · home-screen widget · floating overlay over other apps

PureFxAi วิเคราะห์ข่าวอย่างไร

  1. แอปดึงข่าวทองล่าสุดจากฟีดแดชบอร์ด, Google News (ไทย/อังกฤษ), Yahoo Finance (GC=F) และหัวข้อ Kitco
  2. แต่ละการ์ดมีป้ายผลกระทบเบื้องต้น และลิงก์เปิดข่าวต้นทาง
  3. ถ้ามี API key ในตั้งค่า PureFxAi จะสรุปภาพรวมและอธิบายว่าทำไมแต่ละพาดหัวถึงเอียงหนุน / กดดัน / เป็นกลาง ต่อราคาทอง
  4. ผลถูกแคชในเครื่องตามรหัสข่าวและภาษา เพื่อไม่ยิง API ซ้ำทุกครั้งที่เปิด
  5. หากข่าวนั้นมีผลแรง (ขาขึ้นหรือขาลงชัด) แอปสามารถเด้งแจ้งเตือนแบบ SMS ตามช่วงเวลาที่ตั้งไว้

แบรนด์ในแอปใช้ชื่อ PureFxAi เท่านั้น ไม่โชว์ชื่อโมเดลหรือผู้ให้บริการภายนอก

How PureFxAi news analysis works

  1. The app pulls the latest gold headlines from the dashboard feed, Google News (Thai/English), Yahoo Finance (GC=F), and Kitco headlines.
  2. Each card keeps an impact badge and a link to the original source.
  3. With an API key in Settings, PureFxAi writes an overall summary plus why each headline looks bullish, bearish, or neutral for gold.
  4. Analyses are cached on-device by news id and language so the API is not called on every open.
  5. If a story looks strongly bullish or bearish, the app can send an SMS-style alert that respects your interval and mute settings.

The UI is branded PureFxAi only — it never shows third-party model or vendor names.
